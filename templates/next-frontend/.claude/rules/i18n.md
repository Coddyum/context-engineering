# Rule — internationalisation

Referenced by `CLAUDE.md`.

- **Zero hardcoded user-facing text.** Everything goes through the i18n layer, no exception.
- Locale files in `src/i18n/locales/<lang>/` — always add every language in the same edit.
- Parity is enforced mechanically by `scripts/check-i18n-parity.sh`.

> Why it is a hook and not a convention: a missing key does not crash. i18next renders the raw
> key or falls back to another language, so the bug ships and is found by a user reading the
> wrong language on a real page. That is the worst shape a bug can take — silent,
> cosmetic-looking, and in front of a customer.
